Installation instructions


First Time Driver Installation Instructions
1.
Extract “fx_w2k_118.exe” to “c:\drivers\video\fx\w2k\118”
2.
When the "Found New Hardware Wizard" window opens, click “Next” to continue.
3.
Select "Display a list of known drivers for this device" and then click “Next”.
4.
Click the “Have Disk” button and browse to the directory that contains the HP Visualize fx driver.
5.
Select the “hpfxlw2k.inf” file. Click “Open” and then “OK”.
6.
This should return you to the "Select a Device Driver" window and "Hewlett-Packard VisualizeFX Series Video" should be highlighted in the list of models. Click “Next”.
7.
Click “Yes” to the “Digital Signature Not Found” warning.
8.
Click “Finish” to complete the driver update.
9.
Reboot the system.
10.
To finish configuring the system please see the “Software deployment guidelines” below.

Driver Update Instructions
1.
Extract “fx_w2k_118.exe” to “c:\drivers\video\fx\w2k\118”.
2.
Right click the “My Computer” icon, and select “Manage”.
3.
Select the “Device Manager” box.
4.
If there is a “Video Controller” (with a question mark) under the “Other Devices” icon, and the “Display Adapters” icon only shows the “Matrox Graphics Millenium G200”, go to step 5. Else, go to step 6.
5.
Double click the “Video Controller” (with the question mark) under the “Other Devices” icon. Go to step 7. 
6.
Click on the “Display Adapters” icon and then double click on “Hewlett-Packard VisualizeFX Series Video”. Go to step 7.
7.
Select the “Driver” tab and then click the “Update Driver” button.
8.
This should start the "Upgrade Device Driver Wizard".  Click “Next”.
9.
Select "Display a list of known drivers for this device" and then click “Next”.
10.
Click the “Have Disk” button and browse to “c:\drivers\video\fx\w2k\116”.
11.
Select the “hpfxlw2k.inf” file. Click “Open” and then “OK”.
12.
This should return you to the “Upgrade Device Driver Wizard “and "Hewlett-Packard VisualizeFX Series Video" should be highlighted in the list of models.  Click “Next”.
13.
Click “Yes” on the “Digital Signature Not Found” warning.

Software deployment guidelines
Post Driver Installation Steps for Windows 2000

1. Verify that VisualizeFX is the Primary Monitor

a. Start the Control Panel: Click Start, point to Settings and select Control Panel.
b. Double-click on Display and click the Settings tab.
c. If Hewlett-Packard VisualizeFX Series Video is the only display listed, you are done. 
d. If two displays are listed (Matrox Graphics Millennium G200 and Hewlett-Packard VisualizeFX Series Video), follow the remaining steps to extend the desktop to VisualizeFX.

NOTE: The Matrox device is part of the VisualizeFX card.  It provides VGA functionality and cannot be used at the same time while using VisualizeFX graphics. Thus, you should not extend the desktop to the Matrox device.

e. Select VisualizeFX in the list of displays.  Check 'Extend my Windows desktop onto the monitor' and 'Use this device as the primary monitor'
f. Select Matrox Graphics in the list of displays.   Uncheck 'Extend my Windows desktop onto the monitor'
g. Click the apply button.

2. Disable Mouse Pointer Shadows

The default Windows 2000 mouse pointer may cause problems between the pointer and OpenGL applications. Follow these steps to avoid these problems:
         
a. Start the Control Panel: Click Start, point to Settings and select Control Panel.
b. Double-click on Mouse and click the Pointers tab.
c. Uncheck 'Enable pointer shadow'


Driver Configuration

You should optimize the driver settings to suit the OpenGL application that you are using on your system. This can be done through the driver applet, which is installed automatically with the driver.

1. From the Start menu, click "Settings" then "Control Panel".
2. Double-click the "Display" icon, click on the Advanced button and select the "Options" tab.
3. Select your application in the "Application" list box.   Driver settings (viewed on the right) will be configured to best suit your application. If the application you are using is not listed, select "Compatibility Mode".
4. Click the "Apply" button, then "OK".

For explanations of each setting, click on the question mark (?) in the upper right hand corner of the window and then click on the option for which you want to see an explanation.\

3D StudioMAX version 3 Driver

Copy the hpoglgfx.drv file to the 3D StudioMAX 3 home directory.   (This should be the same directory as the oglgfx.drv file).

Start 3D StudioMAX, and select the Customize->Preferences menu item.  Select the Viewports tab, and select the Choose Driver button in the lower right corner.  Next to the Custom button, you should see a drop down selector.  Select the hpoglgfx.drv  custom driver and click "OK".  Now select the Configure Driver button and configure the driver as follows:

OFF: Redraw Scene on Window Expose
ON:  Use Triangle Strips
ON:  Display Wireframe Objects Using Triangle Strips
ON:  Allow Dual Plane Support
ON:  Use Incremental Scene Updates
ON:  Use BGRA pixel format
ON:  Use Generalized Vertex Arrays

You will need to restart 3D StudioMAX for the changes to take effect.
